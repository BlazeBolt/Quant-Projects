# Stock Portfolio Summary Calculator

## Overview
This is a Python-based command-line application that helps users track and analyze their stock portfolio performance. The program collects information about 3 stocks and calculates key metrics including position values, profit/loss, and percentage returns.

## Project Structure
- `stock-portfolio.py` - Main Python script (command-line interface)
- `stock-portfolio.ipynb` - Jupyter notebook version (interactive cells)

## Features
- Interactive stock data collection (symbols, purchase prices, current prices, shares)
- Automated calculations for:
  - Position value (current price × shares)
  - Dollar gain/loss
  - Percentage gain/loss
- Portfolio summary with formatted table display
- Performance analysis showing best and worst performers
- Overall portfolio status indicator

## Technologies
- Python 3.11
- Standard library only (no external dependencies)

## How to Use
Run the program and follow the prompts to enter:
1. Stock symbol (e.g., AAPL, TSLA, GOOGL)
2. Purchase price per share
3. Current price per share
4. Number of shares owned

The program will display a comprehensive portfolio summary with performance metrics.
